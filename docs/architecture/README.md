# docs/architecture — Guia

## O que é esta pasta

Documentos que descrevem seções ou comportamentos não-óbvios das 6 landing
pages que são grandes demais pra caber como uma linha no `CLAUDE.md` (ex.:
como o embed de mapa funciona, como o GTranslate está configurado). São
espelhos do estado atual — sem histórico de implementação.

Convenções que valem pras 6 páginas em geral (não uma seção específica)
ficam direto no `CLAUDE.md`, seção "Convenções ao editar" — não aqui.
